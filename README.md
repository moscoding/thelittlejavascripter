# The Little JavaScripter

Четырёхдневный интенсив по JavaScript от [Moscow Coding School](http://moscoding.ru), 2014.
Автор карты знаний, тестов и заданий — [Сергей Сурганов](http://surganov.com).

Сайт восстановлен в 2026 году из [Wayback Machine](https://web.archive.org/web/*/thelittlejavascripter.com*)
(оригинальный адрес — `thelittlejavascripter.com`, корень редиректил на `/day1`).

## Что восстановлено

- `day1.html` … `day4.html`, `links.html` — последние полные снимки страниц (2014–2016);
- общий `stylesheets/day.css`, `stylesheets/day1.css`, jQuery, картинки дня 1, фавиконки.

## Чего нет

Архив не сохранил эти файлы, поэтому на них стоят заглушки:

- логотипы The Little JavaScripter и MCS — заменены текстом;
- файлы упражнений (`files/day*/exercises/*.js`), проекты дня 3 (`*.zip`), `boilerplate.zip`, `js-knowledge-map.pdf` — ссылки неактивны;
- картинки к упражнениям дня 2 и большая часть картинок дня 3–4 — скрыты;
- `stylesheets/day2.css`, `day3.css`, `links.css` — для `links.html` добавлены минимальные стили;
- интерактивный тест `/exam/types/` (не сохранились `exam.js` и `exam.css`) — страница убрана.

Главы книг *JavaScript: The Definitive Guide* и *JavaScript: The Good Parts*, которые лежали на сайте в PDF,
намеренно не включены: ссылки ведут на страницы книг на сайте O'Reilly.

Все правки восстановления собраны в `stylesheets/restore.css`; остальная разметка — как в архиве,
без счётчика Google Analytics.
