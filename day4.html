Nodeschool.io: Functional Javascript
Сборник задач по функциональному подходу в JS

Концепты

  • scope, global, local, block scope (let/const), closure, IIFE, modules (import/export)
  • arrays and standard method’s library
  • function invocations: function, method, call/apply, constructor
  • high order functions
  • polymorphism, arguments, rest/spread, default parameters
  • hoisting
  • this: objects and methods, binding
  • async: setTimeout, setInterval, Promise, async/await
  • OOP, objects, class, new keyword, methods, this, cascading/chaining
