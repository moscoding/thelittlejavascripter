Типы данных
В JavaScript семь примитивных типов данных: числа (Number), большие целые числа (BigInt, с ES2020), текстовые строки (String), булевый тип (Boolean), символы (Symbol, с ES2015) и два служебных значения — undefined и null. Всё остальное — объекты (Object): массивы, функции, регулярные выражения, даты и т. д.

Операторы
Операторов много, и они все разные. Их можно классифицировать по количеству операндов (унарный, бинарный, тернарный) и по расположению относительно операнда (префикс, инфикс, постфикс).

Некоторые операторы ведут себя по-разному в разных контекстах. Например, оператор + в одном контексте обозначает сложение чисел, а в другом — соединение строк.

Таблица приоритетности выборочных операторов

  • . ?. [] (refinement, optional chaining)
  • () new (invocation, create)
  • ! - + ++ -- typeof delete (unary operators)
  • ** (exponentiation, ES2016)
  • * / % (Multiplication, division, remainder)
  • + - (Addition/concatenation, subtraction)
  • < <= > >= (inequality)
  • in instanceof (objects and keys)
  • === !== (strict equality)
  • && || ?? (Logical and, Logical or, nullish coalescing)
  • ?: (ternary)
  • = += -= *= /= %= **= &&= ||= ??= (assignment)
  • , (comma)

При использовании операторов можно ещё использовать и скобки, чтобы (как в школе!) избежать путаницы в выражениях вида: 4+6 * 3 → (4+6) * 3

Выражения
Операторы + данные = выражения (expressions). Многие операторы будут знакомы ещё со школьной арифметики и математической логики. Наряду с операторами в этих тестах ещё используются и вызовы функций вроде Math.pow (возведение в степень; с ES2016 есть и оператор **) или Math.abs (модуль числа).

Как ни странно, выражение 0.1 + 0.2 === 0.3 возвращает false. Всё из-за особенностей того, как JavaScript хранит числа с плавающей точкой в памяти (стандарт IEEE 754).

Языковые конструкции
Ключевое свойство выражений в том, что они возвращают результат в то место, где они были использованы. Но что это за программа, которая не умеет сохранять полученный результат? Для этого есть переменные: с ES2015 их объявляют через let (значение можно менять) и const (нельзя переприсвоить). Старый var встречается в коде, написанном до 2015 года.

Лексическая структура
JavaScript очень много прощает — позволяет пропускать точки с запятой, ставить лишние пробелы и иногда не ставить фигурные скобки. Подобная разболтанность может вести к серьёзным багам, поэтому стоит заранее договорить о стиле написания кода.

Функции
Ещё одно средство абстракции — это функции. Они нужны для того, чтобы использовать набор инструкций несколько раз. Все функции возвращают какое-то значение, пусть даже и undefined.
